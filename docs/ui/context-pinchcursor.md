# 连续手势鼠标

## 用户

使用电脑摄像头完成瞄准、点击、拖动和滚动的人，需要能随时确认是否已接管指针、手势是否已确认、动作是否真正执行，以及如何停止控制。

## 产品

PinchCursor 是 PySide6 桌面工具。连续动作由独立控制线程判断，界面读取不可变快照；辅助点选、校准和自定义手势通过设置调整。[控制架构](../CONTROL_ARCHITECTURE.md)

## 约束

- 保留本机原生桌面界面、中文和英文、已有设置及保存/取消行为。
- 主窗口支持 1000×660；设置中的指针控制和校准在 900×640 可直接到达。
- 界面重构不参与输入决策；渲染停顿不得延迟原生释放。
- 保留一次明确的开始/停止入口，摄像头仅在用户启动后开启。

## 用户控制

权限缺失显示可恢复的状态，不自动开摄像头。捏合候选、捏合确认和点击成功使用不同反馈。没有成功执行的系统动作，不显示成功。窗口内 Escape 只停止已有控制，不触发开始。

## 验收

- 主界面直接呈现当前动作阶段和下一步操作。
- 指针、激活方式和摄像头摘要分别打开对应设置位置。
- 中文、英文以及就绪、权限缺失状态下，主要操作无裁切和重叠。
- 手势速查来自实际绑定，补充手势按需展开。
- 设置摘要具有原生按钮角色、可访问名称及键盘操作。

## 待验证
