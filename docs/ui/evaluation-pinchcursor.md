# 手势控制主界面与控制设置

## 优先问题

### 当前手形不能说明动作是否已经执行

预览底部的手形标签无法区分候选捏合、确认捏合、点击成功和取消。新增操作反馈读取控制快照和真实派发结果，显示瞄准、捏合、松开的离散步骤；失败不会显示成成功。[反馈模型](../../gui/interaction_feedback.py)

### 指针调节和校准分散

原控制页面先呈现激活参数和自定义触发手势，平滑度等常用设置位于高级诊断。控制页改为「指针与点击 / 激活 / 高级」：默认页集中映射、精细控制、点选辅助及校准。[设置实现](../../gui/settings_dialog.py)

### 操作结果只停留一帧

点击和失败结果可能被下一帧的瞄准状态立即覆盖。点击结果保留 0.7 秒，未执行结果保留 1.5 秒；新候选、拖动、手部丢失或停止立即取代旧反馈。[呈现策略](../../gui/interaction_feedback.py)

### 单次操作失败被表述为整个控制中断

不支持的操作和单次派发失败不等于控制线程停止。普通操作失败显示「操作未执行」；追踪或运行时中断使用中断反馈。[状态测试](../../tests/test_interaction_feedback.py)

### 可点击摘要缺少按钮语义

原摘要是可按键触发的普通容器。摘要改为原生按钮，保留整行点击、键盘操作、正确可访问名称和按压动作，并让按钮尺寸包含其标签布局。[可访问性测试](../../tests/test_summary_row_accessibility.py)

## 保留的设计

开始/停止使用同一个主要操作。权限问题就地恢复。摄像头关闭时明确显示关闭原因。基础操作直接可见，其他已绑定手势可展开。校准及其他设置仍遵循保存/取消边界。

## 验证

真实 Qt 控件截图覆盖中文主界面、权限缺失、英文 1000×660、捏合确认示例，以及指针和激活设置。确认示例标记为模拟手势回放。集成测试检查界面边界、内容重叠、成功/失败反馈、Escape 和设置导航。[工作区测试](../../tests/test_control_workspace.py)
